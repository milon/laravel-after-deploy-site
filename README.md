# Laravel After Deploy - book site

The marketing/landing site for the book *Laravel After Deploy: Architecture,
Performance, and Operations at Scale*.

Live at **https://laravel-after-deploy.milon.im**.

## Identifiers

- Paperback ISBN: `979-8193747345`
- US Amazon ASIN: `B0HG36PSDJ`
- Amazon URL: `https://mybook.to/laravel-after-deploy`
- PDF & EPUB URL: `https://store.milon.im/laravel-after-deploy`

The Amazon URL is a Booklinker smart link. It sends the reader to their local
storefront, so the site does not need a separate ASIN per marketplace. The US
ASIN is kept here as the source identifier.

PDF and EPUB are sold from the Blink store at `store.milon.im`. Paperback and
Kindle stay on Amazon.
