# Laravel in Production - book site

The marketing/landing site for the book *Laravel in Production: Architecture,
Performance, and Operations at Scale*. Plain HTML, CSS, and vanilla JS - no
build step, no dependencies.

Live at **https://laravel-in-production.milon.im**.

## Working locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000/
```

Deployed via GitHub Pages directly from this repo (see `CNAME` for the custom domain).
